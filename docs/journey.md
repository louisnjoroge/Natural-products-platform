# Asili — Thinking Log & Where We Left Off

This file tracks how the idea has evolved. When a new concept comes in, it gets logged here, checked against the guiding principle, and the "Where we left off" section is updated.

## Guiding principle (the filter for every new idea)
**Asili is an aggregator.** It helps buyers find artisans and their products. No stock, no consignment, no premises, no holding makers' money.
